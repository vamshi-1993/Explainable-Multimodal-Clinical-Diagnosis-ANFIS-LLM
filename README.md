# Explainable-Multimodal-Clinical-Diagnosis-ANFIS-LLM
Multi-organ diagnosis system (brain MRI, skin dermoscopy, retinal OCT) combining CNN feature extraction, a learned bottleneck, and a custom ANFIS fuzzy-logic layer for interpretable classification with IF-THEN rules. Includes Grad-CAM/segmentation explainability, a tool-calling LLM agent (Gemini) for guidance, FastAPI backend, React frontend.
